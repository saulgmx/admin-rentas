# admin-rentas

Aplicación personal para mantener sincronizados al dueño y al administrador de un departamento en renta mixta (vacacional y mensual) en México: servicios, pagos, ocupación, gastos y mantenimiento.

## Enfoque

- **Arquitectura:** monolito modular.
- **Metodología:** desarrollo guiado por especificaciones (Spec-Driven Development).
- **Cliente:** PWA *mobile-first*.
