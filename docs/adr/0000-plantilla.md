## Listo para aceptar

Un ADR pasa de *Propuesto* a *Aceptado* solo si todas las casillas están marcadas (criterios ECADR de Olaf Zimmermann). Si una no aplica, se explica por qué.

- [ ] **Evidencia:** hay razones para confiar en que la decisión funciona (documentación verificada, prueba de concepto o experiencia previa). No se marca mientras quede algo por confirmar; si algo no se puede confirmar sin implementar, el ADR dice qué se hace si falla.
- [ ] **Alternativas:** se compararon al menos dos opciones, con el motivo de cada descarte.
- [ ] **Acuerdo:** el dueño del proyecto revisó y aprobó la decisión.
- [ ] **Documentación:** no queda ningún `[POR DEFINIR]`. Lo que no es de nivel ADR está en su documento, con enlace.
- [ ] **Implementación y revisión:** se sabe en qué cambio o tarea se implementa y cuándo conviene revisar la decisión.
